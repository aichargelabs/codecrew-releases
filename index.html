Agentic code terminal

Your terminal.
With a crew.

CodeCrew brings agentic coding into the command line. Run one command and start working with a crew in your terminal.

install — codecrew stable v1.0.1
Windows · PowerShell
irm https://codecrew.aichargelabs.com/install.ps1 | iex
macOS / Linux
curl -fsSL https://codecrew.aichargelabs.com/install.sh | sh

note: macOS and Linux builds are coming soon — the script tells you if your platform is not published yet.

Pin a version

Set the variable before running the installer.

PowerShell$env:CODECREW_VERSION="1.0.1"
shCODECREW_VERSION=1.0.1
